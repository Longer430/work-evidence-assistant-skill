# 工作留痕助理 · Work Evidence Assistant

一个中文 Codex Skill：把零散工作事实整理成可检索的记录，检查缺项、区分证据等级，并按事项做季度整理。

## 来源

根据用户在“创建工作留痕技能”对话中提供的规则整理。未找到上一轮实际生成的技能文件，本仓库为依据原始需求重建的发布版本。

## 安装与使用

将本仓库下载后，把含有 `SKILL.md` 的目录命名为 `work-evidence-assistant`，放入本机 Codex 技能目录（通常为 `~/.codex/skills/`）。重新打开 Codex 会话后调用：

```text
$work-evidence-assistant
帮我整理下面这件事：……
```

也可以说“整理一下！”，整理已提供的上季度记录。技能本身不定时运行，也不会自动访问公司系统或备份文件。

## 核心规则

- 每条一件事：时间、人、具体动作、带数字的结果、证据位置。
- 缺项标“缺”，不补写事实，不估算数字。
- 区分系统／邮件／工单、群聊／纪要／版本、截图／录音、个人回忆。
- 每次输出：整理后的记录、缺什么、证据等级、下一步一句话。

见 [虚构用法示例](examples.md)。证据等级用于整理，不代表真实性认证或法律效力判断。

## 隐私

仓库仅存技能规则、说明和虚构示例。不要提交真实工作记录、公司内部链接、聊天记录、截图、录音、账号凭据或密钥。真实记录请保存在公司允许的位置。
